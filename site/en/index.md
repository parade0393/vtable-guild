## Who it is for

vtable-guild targets teams already using ant-design-vue or element-plus in Vue 3 projects.

If you want to keep the table API you know but need dependable virtual scrolling, column width control, theme extensibility and a maintainable style-override model, this library beats stacking patches on the stock table.
